# AI Song Lyrics Generator

## About the Project

This project is an AI chatbot that generates song lyrics based on a user's chosen theme, background story, and genre.

## Technologies Used

* Python
* Google Gemini AI
* Streamlit
* FastAPI
* REST APIs

## How It Works

1. The user enters a theme, background story, and genre.
2. The frontend sends the information to the backend.
3. Google Gemini AI generates personalized song lyrics based on the user's input.

## What I Learned

Through this project, I improved my skills in Python, AI, APIs, and connecting frontend and backend applications.

## Note

A Gemini API key is required to run this application. Keep your API key private in a local `.env` file.
